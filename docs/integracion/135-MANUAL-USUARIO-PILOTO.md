# 135 — Manual breve de usuario piloto (borrador pre-UAT)

**Estado:** borrador para orientar la sesión; requiere confirmación y correcciones después de UAT. Las pantallas y permisos disponibles dependen del rol y del build habilitado.

## Iniciar y salir

Use únicamente la cuenta institucional que IT haya autorizado para el entorno piloto. No comparta contraseña. Al terminar, use **Cerrar sesión** y cierre la ventana compartida.

## Buscar

Empiece por una frase o término distintivo. Revise la carátula, tribunal, fecha, expediente y fragmento disponibles. Use filtros sólo cuando ayuden a acotar; los operadores de búsqueda avanzada pueden usarse según la ayuda de la pantalla. Un resultado no determina vigencia jurídica ni reemplaza la lectura del documento.

## Abrir un documento

Abra el resultado, compruebe la fuente/procedencia y la página indicada. Use los controles de coincidencia siguiente/anterior para navegar el texto resaltado. Si vuelve a resultados, confirme que la consulta y filtros sigan presentes. Descargar sólo si el rol y las reglas del entorno lo permiten.

## Jurisprudencia, Digesto y revisión

Las acciones de edición/selección/revisión sólo deben ejecutarse por los perfiles autorizados y sobre datos de prueba aprobados durante UAT. Una sugerencia o clasificación no es una decisión editorial ni concede visibilidad pública. Ante una asociación, permiso o metadata dudosa, deténgase y registre un hallazgo; no cambie ACL ni publique.

## Estado

Este manual es provisional. Añadir capturas/instrucciones sólo tras observar el recorrido con usuarios institucionales y validar nombres de pantalla, navegador, roles y vocabulario.
