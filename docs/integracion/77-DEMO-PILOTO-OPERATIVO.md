# Sprint 10 — Guion de demo guiada (15 minutos)

Usar DEV local, sin compartir el archivo local restringido de credenciales. La demo usa documentos importados y fixtures limpiables.

| Minutos | Perfil / recorrido |
|---|---|
| 0–2 | ADMIN: login, dashboard, conteos Digesto/OCR/revisión; aclarar que son DEV. |
| 2–5 | LECTOR: filtrar colección, abrir documento, ver metadata/procedencia y highlight. |
| 5–8 | REVISOR: inspeccionar clasificación sugerida, aprobar/rechazar fixture y consultar historial. |
| 8–11 | JURISPRUDENCIA: revisar asociación, seleccionar con motivo y observar estado/historial. |
| 11–13 | DIGESTO: colección, tema/tag, agregar/quitar membership de fixture; confirmar que el vínculo no borra el PDF. |
| 13–15 | ADMIN: revisar pendientes y completar checklist de aceptación. |

Checklist por perfil: Secretaría/Jurisprudencia (búsqueda, match, motivo, sumario/tema, historial, ACL); Digesto (taxonomía, membership, filtro y procedencia); Consulta (filtros, lectura/descarga, viewer y errores); Admin (indicadores, drill-down, roles y auditoría). Para cada punto registrar `Aprobado / Rechazado / No observado`, comentario y responsable. Aceptación institucional pendiente.
