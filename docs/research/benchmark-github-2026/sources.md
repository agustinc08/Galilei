# Fuentes y método de verificación

## Método

Fecha de corte 25-10-2026. Se priorizaron repositorios, README, documentación de mantenedores, archivos de licencia y releases. Las estrellas/forks y fechas de actividad son una instantánea de GitHub, variables con el tiempo. Un push reciente no acredita mantenimiento, seguridad o calidad. El contenido de README sobre corpus y evaluación se atribuye al proyecto salvo verificación independiente. No se descargó ni ejecutó código.

Cuando GitHub API devolvió NOASSERTION o no mostró licencia, se informa esa limitación; una licencia debe verificarse en los archivos del proyecto antes de adoptar código. Las licencias de software tampoco otorgan derechos sobre fallos, PDFs, bases o conectores de terceros.
